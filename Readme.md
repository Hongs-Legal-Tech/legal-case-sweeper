\# Legal Case Sweeper



An AI-powered desktop application designed for legal professionals and researchers. It recursively scans directories of PDF legal documents, extracts text locally, and leverages frontier Large Language Models (LLMs) to classify, filter, and summarize case law into a structured Excel report.



\## Features

\* \*\*Multi-Provider AI Architecture:\*\* Native support for OpenAI (GPT-6, GPT-5.6), Anthropic (Claude 5, Claude Fable), Google (Gemini 3), and Custom/Local endpoints (Ollama, vLLM).

\* \*\*Intelligent Filtering:\*\* Automatically detects whether a document is a substantive opinion on the merits (ignoring scheduling orders, writ denials, etc.) and filters based on a user-defined topical query.

\* \*\*Strict Summarization:\*\* Enforces a rigid 3-sentence output constraint (Facts, Analysis, Holding) for rapid review.

\* \*\*Robust Pipeline:\*\* Features exponential backoff for API rate limits, batched I/O Excel saving to prevent disk bottlenecks, and generator-based file traversal for massive directories.

\* \*\*Local Extraction:\*\* PDF text extraction is performed entirely on your local machine using `pdfplumber`. Only the extracted text is sent to the AI provider.



\## Prerequisites

\* Python 3.9+

\* Valid API Key for your chosen provider (OpenAI, Anthropic, or Google GenAI), OR a local OpenAI-compatible inference server (e.g., Ollama) running on your machine.

Disclaimer

Data Privacy: Unless you are using a local model via the "Custom/Local" provider option, the text extracted from your PDFs is transmitted to third-party APIs (Google, OpenAI, Anthropic). Do not use this tool with sealed, confidential, or privileged documents without verifying your API data processing agreements.

Not Legal Advice: The summaries generated by this tool are produced by artificial intelligence and may contain hallucinations or inaccuracies. Always read the full source opinion before citing it in legal filings.
